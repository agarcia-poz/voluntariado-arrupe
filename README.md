# Voluntariado Arrupe · Pastoral CUSAFA

App para coordinar el Voluntariado Arrupe del Centro Universitario Sagrada Familia (Úbeda): Pastoral, coordinación de cada entidad y voluntariado.

- `docs/`: la web, publicada con GitHub Pages en https://agarcia-poz.github.io/voluntariado-arrupe/
- `apps-script/`: el script de Google que guarda los datos en una hoja y una carpeta privadas de Drive
- `GUIA.md`: puesta en marcha paso a paso

Libres para servir.
